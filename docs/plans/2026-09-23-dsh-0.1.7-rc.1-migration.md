## 改动

**Host**
- `src/config.ts`：`Config` 字段 `name`/`revision` 加 `.volatile()`；新增 `BrandTextEntryConfig`（`Volatile<string>` 字段）。
- `src/settings.ts`：删除 `SettingsScope` import 与 `settings.register`（含 watch/isUnloading/already-registered 去重逻辑）；改为 `settings.configure({ auto: false }, ctx.fiber)`；`source()` 每次读 `config.name.get()`/`config.revision.get()`。
- `src/index.ts`：`apply(ctx, config: BrandTextEntryConfig)`。
- `src/gateway.ts`：`import type {} from '@deepseek-ai/dsh-settings'` 以获得 `ctx.settings` 类型合并；写入仍走 `settings.update('sidebar-brand-text', patch)`（entry id = 组合 row id，值持久化到 profile 的 `cordis.patch.yml`）。
- `@deepseek-ai/schemastery` `^3.18.1` → `^3.18.4`（`.volatile()` 起始版本）；移除未使用的裸 `schemastery` devDep。

**Web Client**
- `src/client/index.ts`：`settings.plugin.item` → `plugins.row.config`，key `@huanlin/dsh-plugin-sidebar-brand-text#sidebar-brand-text`；`dsh.client.inject` 增 `@deepseek-ai/dsh-client-ui-plugin-manager`、去 `@deepseek-ai/dsh-client-ui-settings-plugins`。
- `src/client/BrandTextCard.tsx`：props 增 `PropsRuntime<'plugins.row.config'>`；`view === 'summary'` 渲染 `t('card.intro')`（hooks 之后分支）。
- `src/client/titleWriter.ts`：`SessionListSnapshot.current` 改为可选（见 pending）。

**测试/配置**
- `tests/registration.client.spec.ts`：断言槽名与 key 更新。
- `tsconfig.json`：paths 删 `ui-settings-plugins`，增 `ui-plugin-manager`。
- 重建 `lib/`（`tsdown` + `tsc`）。

## pending / 残余风险

- **标题的会话名前缀失效（pending review）**：`titleWriter` 原本从 `ctx.sessions.list` 快照读 `current`（当前会话 id）+ `byId[id].title`，把浏览器标题写成 `<会话名> — <品牌名>`。rc.1 的 `ISessions.list` 快照类型变为 `SessionListState = { ids, byId, phase, projectionsBySession }`（`packages/api/session-controller/src/client/sessions/service.ts`），**不再携带选中会话**——导航/选中已移出 sessions 域。本次把 `current` 降为可选以通过 rc.1 类型检查：品牌名覆盖、以及"当前会话名"前缀在提供了 current 的调用方仍有效，但真实 rc.1 运行时拿不到 current，标题退化为**仅品牌名**。重接选中会话来源（view owner 侧）后即可恢复前缀；在未确认该来源前不改。
- **本地 dsh checkout 版本**：`D:/Projects/deepseek-harness/dsh` 停在 `0.1.5-rc.2+139`，不含 `ui-plugin-manager`；仓内绝对 paths 无法解析 rc.1 专有类型。本次用临时 `tsconfig.rc1.json`（paths 指向 registry 0.1.7-rc.1）完成静态校验，校验后已删除；工作区 link 语义未变。
